About

Reach-Ops is a prototype disaster-response accessibility dashboard for the 15 August 2026 Flores earthquake.

Built on OSM roads + Kontur population + DuckDB-WASM, with a Rust/petgraph engine in the browser. Accessibility is measured from aid hubs via a multi-source Dijkstra; broken roads cut off the network downstream.

Hubs are placeholder regency centroids — swap in real airstrip/port/warehouse coordinates when a coordinator supplies them.
